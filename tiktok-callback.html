Connect TikTok

For the Ooz Reels Bot. This page never sends your code anywhere; it only shows it to you.

You'll sign in to TikTok, approve, and come back here with a code.

  1. Open the bot's GitHub Actions page → reels-bot → Run workflow.
  2. Set task to tiktok-connect and paste the code into code.
  3. Click Run workflow. The bot sends your TikTok token to you on Telegram.
